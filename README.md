# CardStock

A native macOS editor for flat-file blogs and portfolio sites.

CardStock edits your site's files on your Mac, can keep them on **GitHub** for version history, and works with **Cloudflare Pages** (or any Git-connected host) to publish your site automatically.

> Status: early development.

## Download

Get the latest `.dmg` from [Releases](https://github.com/wesvasher/CardStock-Releases/releases/latest). Requires macOS 26 or later.

Builds are not yet notarized by Apple. On first launch, right-click CardStock.app → **Open**, or allow it under System Settings → Privacy & Security.

CardStock checks this page for updates in **Settings → About**.
